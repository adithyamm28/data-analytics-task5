# Maincraft Technology — Task 5
## Sales Performance and Customer Analytics Dashboard

### Project Overview
This project demonstrates the concepts covered in the Maincraft Technology Data Analytics & Business Intelligence Task 5, including advanced DAX, data modelling, dashboard optimization, customer segmentation, and executive dashboard design.

### Objectives
- Analyze sales, profit, and order performance.
- Rank products by sales.
- Compare sales across periods.
- Analyze customer value and product contribution.
- Build an interactive Power BI executive dashboard.
- Document report optimization and business insights.

### Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Git
- GitHub
- CSV / Excel

### Project Structure
- `data/` — Practice sales dataset
- `dax/` — DAX measure reference
- `docs/` — Project report and methodology
- `screenshots/` — Dashboard screenshots
- `Sales_Performance_Customer_Analytics.pbix` — Power BI report

### Key Features
1. Sales and profit KPI cards
2. Sales trend analysis
3. Regional and category performance
4. Product ranking using RANKX
5. Previous-year sales comparison
6. Customer segmentation
7. ABC product analysis
8. Performance testing and optimization
